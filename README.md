# O_Clock_Store 🕰️

Plantilla para una plataforma de venta de relojes de lujo con interfaz interactiva y responsiva.

---

## 📋 Descripción

O'Clock Store es un proyecto web que presenta un catálogo exclusivo de relojes de lujo de marcas prestigiosas. Incluye navegación intuitiva, listado de productos, carrito de compras y lista de deseos.

---

## 🏗️ Estructura del Proyecto
```
O'Clock Store/
├── index.html # Página de inicio
├── catalogo.html # Catálogo de productos
├── Contactos.html # Página de contacto
├── ListaDeseados.html # Lista de deseos
├── css/ # Estilos
│ ├── bootstrap.css # Framework Bootstrap
│ ├── estilo.css # Estilos personalizados
│ └── estiloISSC.css # Estilos adicionales
├── js/ # JavaScript
│ └── bootstrap.bundle.js # Funcionalidades Bootstrap
├── imagenes/ # Imágenes del sitio
├── imagenes richard-mille/ # Imágenes de productos Richard Mille
└── Subpagina-*.html # Páginas de productos individuales
```

---

## 🚀 Uso

1. Abre `index.html` en tu navegador web
2. Navega entre las secciones usando el menú
3. Explora el catálogo de relojes
4. Agrega productos a tu lista de deseos o carrito
5. Contacta a través del formulario de contacto

---

## Aclaración importante

Este proyecto es más visual que funcional, por ende no es una plantilla completa por falta de funcionalidades, como agregar objetos al carrito de compras; solo simula algunas agregaciones con algunos relojes.
